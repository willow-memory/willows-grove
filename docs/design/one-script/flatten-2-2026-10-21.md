## §2 Where the pile is

Still willow-bot (seal D2; F-2). `onescript/` there now also holds the reach
(`reach.py`, with `reach_bootstrap.py` as the template each consuming repo
carries as `onescript_reach.py`), `canon.py`, `clock.py`, `words.py`,
`scrub.py`, `sign.py`, a named legacy generator in the stream, `merge_check`
and `diverge`. Consumers reach it only through the reach: willows-grove,
willow-mcp (outside the trust path) and ratatosk. Where there is no one script,
the caller says `unreachable` with a reason, never a guessed path and never a
silent fallback to its old copy. The integration branch is `claude/flatten-2`
(willow-bot, willows-grove, willow-mcp, ratatosk); safe-app-store has none.
