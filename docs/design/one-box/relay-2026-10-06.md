*Append-only. Each session reads this file, adds its own rows to the one-box
grid, appends one baton below, commits and pushes. Nothing above the last
baton is edited. Corrections go in a new baton, not on top of an old one.*

> supposed to be an additive session with all of my sessions from today."

> loop chiefly, without me doing much."

## The loop

| Step | Do | Check |
|---|---|---|
| 1 Read | This file, top to bottom; the last baton names the next free row and the branch tip | `git fetch origin ccr-392b8b73-v809qu`; the tip equals the last baton's tip, or something newer was added, so read that too |
| 2 Add | Write your session's notes doc in `docs/design/one-box/`: `### <ROW> · <title>` sections, bullets `- **Label.** text`, operator's words verbatim | Every box `unattested` unless someone else checked it |
| 3 Grid | `python3 templates/cross-table/cross_table.py new <map> --rows N --cols 5 --after <last map>`, then set `"root": "../../../.."`, fill each cell's `label`/`file`/`pattern`/`mode`/`standing` | `check <map> --with <last map>` exits 0, no shared row letter |
| 4 Write | `fill <map> <doc> --measure`, then `measure <map> --snapshot <snapshot>`; append one line to the README's read-in-order list | `git diff --cached --numstat`: **0 lines removed** |
| 5 Baton | Append a baton below: what you added, next free row, open items with confidence as a percentage | Only appended |
| 6 Push | Commit with the operator's words verbatim and `Persona:`; fetch, confirm the branch hasn't moved, push to `ccr-392b8b73-v809qu` | Hand the operator the new tip hash |

Rules this rests on: CLAUDE.md rule 6 (persona trailer), 7 (tables), 9 (push
when asked: the standing instruction asks), 10 (guesses as percentages), 12
(frozen records stay frozen; later checks go beside them).
