## Q14 resolved (wording)

**Q14 was:** Is one-script's "gate" a fourth Gate beside willow-gate /
kartikeya / leases?

**Answer (desk wording, not an operator seal):** No. One-script *gate* means
a **decision / escalate / authorize step** in the workflow — the same class
as "does this turn get OUT" or "does this ask need a human." It is not a
daemon and not a replacement for willow-gate (library), Kart (sandbox), or
mcp leases.

**Door / sock + authorize:** The one-box IN/OUT doors (UDS + front-end hooks)
are where authorize *runs*. One-script names *when* and *why* the work
pauses; one-box names *which socket and which hook dialect* carry the pause.
