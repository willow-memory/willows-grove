- **IN** is prompt-submit.
- **OUT** blocks the stop and feeds a reason back so the agent continues.
- **START** and **END** are session start and end.

**What this means for the plan:**
- **OUT is verified** on Claude Code, Codex, Gemini CLI, Copilot, Qwen, and
  Cursor (`followup_message`). Windsurf/Goose need the three-dialect OUT
  table ([crosslink-appendix.md](crosslink-appendix.md)); everything else
  gets an `unenforced` row in the capability table.
- **END budgets of 1–3 s** mean SessionEnd work must be queued, never run
  inline. Grove's current `session_end` composite (a willow-mcp subprocess,
  then deposit) almost certainly overruns Claude Code's 1.5 s.

### Agent Client Protocol (ACP)

ACP is JSON-RPC between an editor and an agent, Apache-2.0 with no CLA
([repo](https://github.com/agentclientprotocol/agent-client-protocol)).

**Who speaks it:**
- **Natively:** Gemini CLI, Cursor, Copilot (preview), Cline, Goose,
  OpenCode, Kiro CLI, Qwen Code, Junie and OpenHands.
- **Through adapters:** Claude
  ([claude-agent-acp](https://github.com/zed-industries/claude-agent-acp),
  Apache-2.0) and Codex
  ([codex-acp](https://github.com/agentclientprotocol/codex-acp), Apache-2.0).

**How the doors map:**
- **IN:** `session/prompt`.
- **OUT:** a `stopReason: end_turn` can be followed by a proxy-sent
  follow-up `session/prompt`.
- **Tool gate:** `session/request_permission`.
- **START:** `session/new`, `/load` or `/resume`.
- **END:** `session/close` **stabilized** 2026-04-23 via
  `sessionCapabilities.close` (↑V 2026-10-02). Without the capability:
  turn-cancel or kill process. Full table of which agents advertise `close`
  remains **?**.

**The proxy-chains RFD** is still a **draft**
([V](https://github.com/agentclientprotocol/agent-client-protocol/blob/main/docs/rfds/proxy-chains.mdx);
confirmed Draft on RFD Updates 2026-10-02). It adds `proxy/successor` and a
"conductor". **sacp-conductor** is usable while the RFD stays Draft. This
only covers ACP-speaking front ends; native TUIs still need shell hooks.

## 4. Ingress and vendor choice (D10)

The operator excluded cloudflared and Tailscale-hosted Funnel on a vendor
criterion ("their eager willingness to work with the current DoD").

**What was found about Tailscale (2026-10-01):**
- About $275M raised; a $160M Series C in April 2025 at about a $1.4B
  valuation (Accel, CRV, Heavybit).
- "On a likely IPO track, although any IPO is several years out."
- It publishes guidance for use in FedRAMP environments and is not itself
  FedRAMP-authorized.
- No specific DoD contract was found.

**Alternatives:**
- **Headscale** (BSD-3) is a self-hosted control server. Tailscale doesn't set
  its direction, but it runs Tailscale-authored clients.
- **NetBird** is AGPL-3, so it is outside the licence filter for code.
- **frp** (Apache-2.0) on an operator-owned server is the choice.

**The decision:** no tunnel by default; willow-bot polls GitHub; claude.ai's
remote MCP is opt-in.

## 6. The gap-pass checklist (re-runnable)

Run it as `python3 checklist.py docs/design/one-box/README.md`. A keyword hit
is only a candidate. The second step is to read each hit's context, which on
2026-10-01 reclassified 8 false matches. Results are in README §15.
