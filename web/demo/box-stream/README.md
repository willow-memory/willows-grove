# The box stream demo

Every sketch from the 2026-10-08 UI session, split off from the design docs into
one demo. Grove serves it at
`http://127.0.0.1:8766/web/demo/box-stream/index.html` ([`index.html`](index.html)).

These are sketches with example and fictional content. No model runs, nothing is
sent, and the checks shown under each sentence are written in, not computed. The
design they illustrate is in
[`docs/design/one-script/local-flow-and-ui.md`](../../../docs/design/one-script/local-flow-and-ui.md)
§5 and
[`docs/design/one-script/box-stream-surfaces.md`](../../../docs/design/one-script/box-stream-surfaces.md).
